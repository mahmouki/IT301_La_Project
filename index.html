Lab Two: Semantics

In Lab Two, I worked with semantic HTML elements to organize the content of a webpage. Elements such as header, nav, main, section, article, aside, and footer help give a webpage a clearer structure.

Why Semantic HTML Matters

Semantic elements make a page easier to understand and maintain. They also help browsers and assistive technologies understand the purpose of different parts of a webpage.

Lab Four: Styling with CSS

This section demonstrates the required CSS properties directly on my website.

Required CSS Properties

color: This text is a different color.

background-color: This area has its own background color.

border: This box has a thick, visible border.
box-shadow: This box has a visible shadow.
border-radius: These corners are visibly rounded.
padding: This box has extra space between the text and border.

Required Properties Together

This box uses color, background-color, border, box-shadow, border-radius, and padding.

Additional CSS Properties

font-family: This website uses the Roboto font.

font-size: This text is larger than normal.

font-weight: This text is extra bold.

text-align: This text is centered.

text-decoration: This link is underlined.
